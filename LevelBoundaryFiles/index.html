Information About The Tool

How to use the Tool

I assume you already dumped your game copy to your computer and extracted its files. If not you can find lots of guides on the internet. Using the big box below you can upload 'ts_mapdataxx.bin' files from the root of the game's disc. This file contains information on the level boundaries and something about moving objects made in the level but I'm not too sure how the ladder works to be honest. Regardless you can change everything about the file here and, if you have the map file (I recommend exporting from the collision file viewer), you can get a 3D visual of what it looks like. You then select the map you want and export using the big blue button. You can even export it as a Gecko Code for convenience.

What is the difference between soft and hard floors/ceilings for the Arwing?

The soft boundary is where, when you're analog stick is neutral, the Arwing will automatically move to if below/above it. You can go past it with boosting and turning, but you'll always be pulled up/down. The hard boundary is something you cannot ever pass no matter what. Unless its above/below the soft floor/ceiling in which case it does nothing. Ideally the hard floor/ceiling is the absolutely farthest you want to have the Arwing go while the soft is more of a suggestion. This makes it so that the floor and ceiling boundary seem less rigid as flying upward into an invisible floor would be weird.

Why do 2 Inputs appear in Advanced Mode?

One input, the one shown when not in advanced mode, is easier for us as humans to understand. The other is the raw value the game will see. The reason for the second one is to allow for more customizability in what you want the file to contain.
