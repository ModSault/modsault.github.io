Information About The Tool

How to use the Tool

I assume you already dumped your game copy to your computer and extracted its files. If not you can find lots of guides on the internet. Using the big box below you can upload 'ts_cammotxxy.bin' files from the root of the game's disc. You will then be able to view and edit all information regarding the camera introduction at the start of Vs Mode matches. Once happy with the changes select the map you want it for and click the blue button to download it. Or copy it as a Gecko Code for more convenience.

How does the file work?

The file contains positions and angles for the camera to go to called keyframes. It takes roughly half a second to reach the next keyframe. The first and last keyframe may not be reached because of the fade in and out. The filename ending with 'a' is used when on-foot is selected. The filename ending with 'b' is used when on-foot isn't selected and the Arwing/Wolfen is. And the filename ending with 'c' is used if only the Landmaster is selected.

FOV looks small despite having a large value

FOV values greater than or equal to 180 cause strange visuals. I recommended not using values that high.

Why are there 2 inputs in Advanced Mode

One of which, the one shown when not in advanced mode, is easier for us as humans to understand. The other is the raw data the game will see. Change whichever you prefer.

How to report bugs

I have a small audience so doing anything would get my attention. Using GitHub issues would be best but even a Reddit DM would work if you really wanted to (assuming I get an email).
